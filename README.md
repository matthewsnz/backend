# E-commerce Full Stack

Projecte de comerç electrònic de jocs de taula.

## Tecnologies

- React
- Node.js / Express
- MongoDB
- Docker
- Mongoose
- JWT
- bcrypt
- Postman

## Funcionalitats

- Gestió de productes (crear, consultar, modificar i eliminar).
- Gestió de categories.
- Gestió d'usuaris.
- Registre i inici de sessió d'usuaris.
- Encriptació de contrasenyes amb bcrypt.
- Autenticació mitjançant JWT.
- Validació de dades.
- Gestió centralitzada d'errors.
- Filtres, ordenació i paginació de resultats.
- Connexió amb MongoDB.

## Execució del projecte

Projecte en desenvolupament.

### Backend

1. Entrar a la carpeta `backend/api`.
2. Instal·lar les dependències:

```bash
npm install
```

3. Configurar les variables d'entorn al fitxer `.env`.
4. Iniciar el servidor:

```bash
npm run dev
```

L'API estarà disponible a:

```text
http://localhost:3000
```
